Global Costmap: Your GPS map. It knows where the highways and permanent
buildings are.

Local Costmap: Your windshield and mirrors. It knows about the car that just cut
you off or the pothole right in front of you.

1. Global Costmap (The "Route Planner")

The Global Costmap is used by the Planner Server to find the best path from
Point A to Point B.

    Size: Usually matches the entire static map of the building/environment.

    Update Frequency: Low (e.g., 1Hz or 5Hz). It doesn't need to refresh constantly because walls don't move.

    Coordinate Frame: Fixed to the map frame.

    Goal: To find a path that avoids permanent obstacles (walls, pillars) over a long distance.

2. Local Costmap (The "Obstacle Avoider")

The Local Costmap is used by the Controller Server to calculate the actual
velocity commands (v,ω) sent to the motors.

    Size: A small "rolling window" that moves with the robot (e.g., 3m x 3m or 5m x 5m).

    Update Frequency: High (e.g., 10Hz or 20Hz). It must react instantly to people walking by.

    Coordinate Frame: Fixed to the odom frame (centered on the robot).

    Goal: To dodge dynamic obstacles (people, boxes, other drones) while trying to stay on the path generated by the Global Planner.
